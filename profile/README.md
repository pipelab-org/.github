# PipeLab

Security tools for AI agents.

- **[Pipelock](https://github.com/luckyPipewrench/pipelock)**: open-source agent firewall. It sits between an AI agent and the network and scans HTTP, WebSocket and MCP traffic for credential leaks, prompt injection, SSRF and tool poisoning.
- **[Agent Egress Bench](https://github.com/luckyPipewrench/agent-egress-bench)**: open corpus, runner and scoring for testing tools that mediate agent egress.
- **[Pipelock Rules](https://github.com/luckyPipewrench/pipelock-rules)**: community detection rules for Pipelock.
- **[pipelock-agent-egress-action](https://github.com/luckyPipewrench/pipelock-agent-egress-action)**: GitHub Action that runs agent-driven CI jobs through Pipelock with verifiable egress evidence.
- **[Agent Evidence Levels](https://github.com/luckyPipewrench/agent-evidence-levels)**: an open standard for grading AI-agent audit evidence.
- **[pipelock-verify-python](https://github.com/luckyPipewrench/pipelock-verify-python)**: Python verifier for Pipelock's signed action receipts.

More at [pipelab.org](https://pipelab.org).
